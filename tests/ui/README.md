# Проверка отображения GenBI

Проверяет production-интерфейс: результат после уточнения попадает в видимую область, последний вопрос остаётся видимым, пустой период показывает нулевой итог и позволяет вернуться к текущему месяцу с сохранением счёта. Данные и Telegram SDK синтетические; реальные операции не создаются.

Запустите сервисы со шлюзом Mini App, затем из этой папки:

```powershell
npm ci
npx playwright install chromium
npm test
```

На Windows можно использовать установленный Edge без загрузки Chromium:

```powershell
$env:PW_CHANNEL = 'msedge'
npm test
```

По умолчанию используется `http://localhost:8080`. Для другого адреса задайте `MINIAPP_BASE` без `/miniapp` в конце. Изображения результата сохраняются локально в `logs/` и не отправляются в Git.
